01. Ordered composition

The ABC and BAC routes contain the same three operators. Because A and B rotate different axes, their order matters. If they were rotations of the same axis, order would not matter.

02. Matched reference

A single late return from an isotropic probe may be statistically identical under either route. Knowing the outgoing state lets the receiver measure the transformation. The early echo can sometimes supply that reference by itself.

03. Local learning

After each ping, a bounded outer-product rule updates a three-by-three forward predictor. Learning to predict return does not prove inverse modeling, useful downstream behavior, or a neuron implementing gauge theory.

Three things called “holonomy” must not be confused

Round-trip packet: ψreturn = C · B · A · ψout (one configured route) Order effect: Δorder = (C·B·A − C·A·B) · ψout (two route alternatives) Internal prediction: εtuft = ψreturn − M · ψreference (ordinary prediction error) Abstract closed loop: H = B⁻¹ · A⁻¹ · B · A (group commutator)

Only the last object is a literal closed four-leg operator loop in this synthetic group setting. Its trace is invariant under a common change of coordinate basis. A Wilson loop in gauge theory additionally requires a specified connection and its parallel transport; cortical anatomy does not establish such a connection. The first three objects are standard dynamical-systems / system-identification quantities.
